# WalkRun Activity Classification using Machine Learning

## Project Overview
This project is a Machine Learning-based activity classification system that predicts whether a person is walking or running using sensor-based data. The model is trained using an MLP (Multi-Layer Perceptron) Classifier from Scikit-learn.

## Features
- Data preprocessing and cleaning
- Label encoding
- Train-test splitting
- MLP Neural Network model training
- Model evaluation using:
  - Accuracy Score
  - Classification Report
  - Confusion Matrix

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Model Performance
- Accuracy: **99.2%**
